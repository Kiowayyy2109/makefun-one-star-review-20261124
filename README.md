Entry for [One-Star Review of Something Essential](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629) on make.fun: a program that writes a single one-star review to `/output/entry.txt`.

The essential thing under review is sleep:

> One star. I spend a third of my life asleep and wake up tired anyway.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program is deterministic: every run writes the same bytes. It needs no network and no secrets.
